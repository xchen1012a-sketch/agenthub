# 上游对接边界（`50-upstream.md`）

> **本文件是本仓上游版本锚点的唯一登记处。** 任何其它文档**禁止**再抄一遍锚点值。
> 与上游对接的"怎么包装、怎么调用"属实现，不在此列。

---

## UP-1 版本锚点唯一（✅ MUST）

上游 DeepSeek Harness 的锁定锚点**只登记在本条**，其它文档只能引用本条、**禁止**复制锚点值。

| 项 | 值 |
| --- | --- |
| 上游仓库 | `https://github.com/deepseek-ai/deepseek-harness` |
| 锁定 commit | `449eedc25715995279c10945d5d7355a143007ce` |
| 锁定版本 | `0.1.7-rc.2` |
| 锁定日期 | 2026-09-27 |

**禁止**在未更新本条的情况下升级上游；升级**必须**在同一次改动中更新本条。

**为什么**：本仓曾把同一个 commit 值抄在 4 处（基线表、代码块、变更流水、修订记录），已构成双源——锚点一旦多处存在，就无法判断哪个是当前值。

---

## UP-2 上游代码只读（✅ MUST）

`deepseek-harness/` 下除 `packages/agenthub/**` 与 `apps/web/config/**` 之外的代码**禁止**修改。

包含上游自带的规则文件（`deepseek-harness/AGENTS.md`、`deepseek-harness/packages/AGENTS.md`）——它们约束上游代码，**不是** AgentHub 的规则来源，**禁止**修改。

**为什么**：上游代码的任何本地改动都会在下次同步时丢失或被误认为冲突，且会让"锚点"失去意义。

---

## UP-3 允许使用的对接面（✅ MUST）

**必须**只通过上游公开的下列面扩展：公开 Service、公开 Hook（事件与瀑布）、公开 Slot。

**禁止**读取上游内部实现、import 上游 `src/` 内部路径、或依赖未公开的行为。

**为什么**：公开面是上游承诺的兼容范围；内部实现随时可能变，依赖它等于把升级变成重写。

---

## UP-4 已登记的对接禁忌（✅ MUST）

以下由实测得出的对接禁忌**必须**遵守：

- **禁止**使用上游保留给固定语义的对话区注入点去承载新形态内容。
- **禁止**注入已被上游原生组件占据的面板；该位置的语义由上游承担。
- 注册任何注入点前**必须**核对上游当前的能力目录（生成物），**禁止**凭记忆写 key 名。

**为什么**：这些位置的 key 域或占用方由上游固定，硬塞会遮蔽上游原生 UI 或静默失效。

---

## UP-5 升级前置义务（✅ MUST）

升级上游**必须**先完成并记录下列评估，未完成**禁止**合入：

1. 上游版本与 commit 变更范围
2. 本仓 `packages/agenthub/**` 使用到的公开面是否有破坏性变更
3. 迁移文件是否受上游持久化格式变化影响
4. `SEC-*` 与 `BND-*` 相关行为是否受影响
5. 回退方案（回退到哪个锚点、需要哪些数据操作）

**禁止**自动跟随上游主分支。

**为什么**：本仓与上游共享 Session 持久化与工具执行链；未评估的升级可能同时破坏身份、审计与审批三条链。

---

## UP-6 上游文档阅读边界（✅ MUST）

上游文档中**只有**下列为权威依据：上游 `architecture.md`、`cordis-primer.md`、`tool-execution-pipeline.md`、`subsystems/` 下的 approval/credentials/invariants/slots/testing/workspace、`glossary.md`、`capability-seams.md`、`defensive-patterns.md`、以及各能力目录的生成物。

其余上游文档**禁止**作为实现依据（它们是历史档案）。

**为什么**：上游文档存在多代并存，未标注权威范围的文档会把人引到已废弃的做法上。
